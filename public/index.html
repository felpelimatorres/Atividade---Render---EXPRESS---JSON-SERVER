CRUD de Pessoas - Node.js + Express + JSON Server

Início Criar (POST) Listar (GET) Editar (PUT) Excluir (DELETE)

Bem-vindo(a)!

Este projeto demonstra as quatro operações do protocolo HTTP (CRUD) aplicadas a um cadastro de pessoas, cada uma em sua própria página:

  • POST — Adicionar nova pessoa
  • GET — Listar todas as pessoas cadastradas
  • PUT — Buscar e atualizar uma pessoa
  • DELETE — Excluir uma pessoa

Os dados são armazenados no arquivo db.json, servido pelo JSON Server através da rota /api/pessoas.
